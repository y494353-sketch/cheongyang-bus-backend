# cheongyang-bus-backend
청양지역 시외버스 출발·도착시간 확인 및 출발시간 안내 백엔드


## 추가한 커뮤니티 기능

- 홈 화면의 내 정보 아래에서 커뮤니티를 열 수 있습니다. 로그인한 계정으로 같은 서버에 연결하면 다른 사용자와 게시글을 공유합니다.
- 전체, 질문, 일반, 정보 탭으로 글을 찾을 수 있습니다. 글쓰기 전에는 질문, 일반, 정보 중 말머리를 선택합니다.
- 목록에는 말머리와 제목, 말풍선으로 표시한 댓글 수가 나옵니다. 글을 선택하면 본문과 댓글 영역이 열립니다.
- 글 제목, 본문, 댓글, 대댓글은 한글로 입력할 수 있습니다. 댓글 영역에서 바로 등록하고, 답글을 누르면 같은 입력칸에서 해당 댓글에 답할 수 있습니다.
- 내가 쓴 글이나 댓글에 다른 사용자가 댓글이나 답글을 달면 알림을 받을 수 있습니다. 내 정보의 커뮤니티 댓글 알림에서 설정하며, Android의 알림 권한이 필요합니다. 앱이 백그라운드에 있으면 알림 표시가 늦어질 수 있습니다.

## 커뮤니티 테스트

커뮤니티가 들어간 Android 프로젝트는 `CheongyangBus/`에서 열고, 백엔드는 `server/`에서 실행합니다.

기존 `cheongyang_bus` DB에는 `db/03_community.sql`, `db/04_community_comments.sql`을 순서대로 적용한 뒤 서버를 재시작합니다. 처음 설정하는 경우에는 `01_schema.sql`과 `02_seed.sql`을 먼저 실행합니다. `01_schema.sql`은 기존 DB를 삭제하므로 사용 중인 DB에 다시 실행하지 마세요.

여러 기기에서 글과 댓글을 공유하려면 같은 백엔드 주소를 사용해야 합니다. 작성자 정보가 저장되기 전에 만든 글은 글쓴이 알림을 보낼 수 없습니다.
